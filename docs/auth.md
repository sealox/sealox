# 登录与授权

谁在用、用的是哪个工作空间。和宿主无关：当前是桌面，以后 mobile 走同一套。界面在哪、长什么样，见 Figma。

## Happy path

1. 未登录：选区域，然后 **使用 Sealos 账号登录**（推荐），或粘贴 kubeconfig。
2. 登录后进入私人工作空间。当前版本登录后不能换区域。
3. 切工作空间：换到那套资源。进行中的对话丢掉。工作空间是身份，不是设置项。
4. 退出登录：清掉本地登录态。对话模型 Key 是人的，退出不清。

邀请、重命名、新建工作空间，跟切空间一样，都是授权域里的事。

## 以后

登录、授权、工作空间准备抽成独立 package，给桌面和 mobile 共用。当前版本没有 mobile 客户端，代码仍住在桌面主进程。不要为还不存在的第二个客户端先发明另一套协议。

## 不要

- 登录后的区域切换（当前版本不做）
- 把工作空间切换做成「设置里改个选项、凭证还是旧的」
- 为 desktop / mobile 各写一套 Sealos 登录协议
