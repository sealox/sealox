# 项目

一次部署产生的集合：名下的应用、数据库、存储桶。模板页点「部署」和「开始」里部署，都进这里，列表不分叉。

删除 / 重启 / 暂停 / 启动见 [operate.md](operate.md)。

## Happy path

1. 打开「项目」。每张卡片是一个实例：备注名、模板、聚合状态。公网域名可点，系统浏览器打开。
2. 卡片状态由名下应用 + 数据库聚合：异常 > 处理中 > 运行中 > 已暂停。应用停了但库还在跑 → 运行中。故障原因和重启次数标红。
3. 点卡片进详情。顶栏：备注名、模板、聚合状态、四个动作。
4. 统计条：应用 / 数据库 / 存储桶 / 定时任务数、创建时间。异常 Pod 横幅点进对应应用。
5. **拓扑**（不是编辑器）：应用在上，库和桶在下。公网 URL 写在应用节点上。磁盘是节点页脚，不是独立节点。不能连线、不能拖节点。点应用进 [apps.md](apps.md)，点库进 [databases.md](databases.md)，点桶不跳。
6. 边只画能证实的引用。猜不出来、且整个项目只有一个应用：把这个应用连到名下全部库和桶。多应用不做这个回退。
7. 没有应用 / 库 / 桶、只有定时任务：不画布。配套资源按类型列在下面。
8. 「最近」点进去就是项目详情。

列表和详情都不展示 secret 明文。
