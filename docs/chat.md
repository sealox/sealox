# 开始（对话）

模糊意图走这里。确定性强的动作（部署这张模板、删除、重启）走按钮，见 [templates.md](templates.md) / [operate.md](operate.md)。

## Happy path

1. 空会话可以打字发送。
2. Agent 按时间线出现：想一段 → 调工具 → 再想 → 正文。thinking 默认收起。工具是独立行，细节截断。有的模型不吐 thinking，时间线可以只有工具行。
3. 只有 assistant 正文当 markdown。用户气泡纯文本。链接用系统浏览器打开。
4. 一轮结束再给下一句。卡住要人回答时，选项画在当前轮，答完才继续。
5. **停止**：停这一轮。不承诺本机正在跑的构建已经停了。
6. **新对话**：清空，回到空会话。
7. **历史**：按当前工作空间过滤。点一条先看到全文；模型侧上下文接不上时，仍显示历史，不要假装还在聊。标题取第一条用户消息，截断即可。不另做重命名。切工作空间后，历史以留下的为准。用户上翻时不要强行拉回最新消息。

「问 Helios」（数据库详情）：切到「开始」、开新对话、输入框预填库上下文，**不自动发送**。

## 对话里部署

分类在 use-sealos，Helios 只提供「开始」和时间线。不要在桌面端重写决策树。

1. 模板店有现成模板 → 和模板页点「部署」进同一个项目。
2. 有官方镜像 → 生成模板部署。有官方镜像就不要从源码构建。
3. 用户自己的源码 → 本机构建再部署。本机缺 CLI 就如实说。

成功标准：公网 URL 返回真页面。否则如实报失败。从「开始」说「部署 n8n」，和模板页点 n8n 是同一类项目。

## 附件

系统文件对话框，多选文件（不是文件夹），读进对话。这不是「拖项目进来部署」。

## 输入框

占位仍写「把项目文件夹拖进来，或粘贴 Git 仓库地址」——**那两个入口没做**。能用的是打字、选文件附件、模板 chips 填输入框。

## 不要

- 点删除 / 重启 / 模板「部署」时先开一轮聊天
- 把资源列表改成对话历史
- 对话搜索、导出、分享、重命名、编辑已发送消息、重新生成
- 把 Helios 历史回放进新会话来假装上下文还在
- 承诺拖文件夹 / 粘贴 git 已经能部署
- 模型选择器（型号见 [settings.md](settings.md)）
