# 模板

商店里的现成应用。点「部署」就是把这一张装进当前工作空间。不问「部署到哪」，也不问实例名。

意图还没成形、或要走源码 / 镜像 / 排障，用「开始」，见 [chat.md](chat.md)。点卡片已经选好模板，不要再让对话去搜一遍商店。

## Happy path

1. 打开「模板」。卡片标题可外开官网说明（那是文档，不是部署）。
2. 点「部署」：该按钮立刻变「提交中」并禁用，防连点。其它卡片照常可点。不弹「确认部署吗」。
3. 绝大多数模板没有必填。有必填（API Key、邮箱）：在卡片上问，不要抄控制台整页表单（可选环境变量、规格、README、价格都不做）。名称像密钥的用密码框。填完确认部署到当前工作空间。
4. 配额不够：停在卡片上，不提交，也不偷偷改小 CPU / 内存。
5. 提交失败：人不走，错误钉在这张卡片上。
6. 提交被受理：打开这个实例的项目详情。不 toast「部署成功」（那时往往还在拉镜像）。不新做进度页，不自动跳「开始」。

## 三次「完成」

| 时刻 | 用户看到 |
|---|---|
| 受理 | 打开项目详情 |
| 就绪 | 项目变成运行中 |
| 可访问 | 公网 URL 可点。未就绪点开 503 是预期，不要藏 URL |

导航只等受理。真成功以公网 URL 能打开为准。

## 第一反应

| 现象 | 做法 |
|---|---|
| 缺必填 | 在卡片上补，不跳走 |
| 没权限 / 余额 / 配额 | 钉在卡片；不要改小规格重试 |
| 受理之后还在拉镜像 | 正常。看项目详情，不要再点一次部署 |

## 不要

- 点部署开浏览器
- 为这次部署新建一条聊天
- 让用户填实例名、选工作空间
- 部署失败自动拉起 agent
- 控制台那种部署页
