# 设置

应用内设置。登录、授权、工作空间见 [auth.md](auth.md)。

## Happy path

设置里有账户和模型。不要为模型新开一页或弹窗。

1. **账户**：当前登录态的只读信息（区域、工作空间等）。退出登录在这里，语义见 [auth.md](auth.md)。
2. **模型**：覆盖，不是替换。入口是设置，不是 [ai-proxy.md](ai-proxy.md)。

| 状态                          | 对话走哪                            |
| ----------------------------- | ----------------------------------- |
| 已接入自己的 DeepSeek API Key | DeepSeek。型号锁死，没有选择器      |
| 未接入                        | 当前工作空间的 AI Proxy。登录就能聊 |

一句说明 + 密码框填 DeepSeek Key。未接入时框是空的。保存前校验；无效不落盘。清除后回到 AI Proxy。退出登录、切工作空间 **不清** Key（Key 是人的，不是空间的）。没 Key 时不禁止对话。

只接 DeepSeek。不接其它厂商。AI Proxy 仍是给用户自己的应用开 Key，本页不改那一页。

## 更新

有新版本：能发现、能看到说明、能下载安装包并用系统打开。Helios **不退出、不替换自己**。探测失败当没发生。

发布 macOS Apple Silicon / Intel 和 Windows x64。不做静默替换：下载并校验安装包后交给系统打开，不覆盖正在运行的 Helios。

## 不要

- 把对话模型设置塞进 AI Proxy 页
- 多厂商 BYOK、没 Key 时禁止对话、型号选择器
- 把登录 / 切工作空间写进本页（那是 [auth.md](auth.md)）
- 让 Helios 自己覆盖正在运行的安装
