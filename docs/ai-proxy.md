# AI Proxy

给**用户自己的应用**开网关 Key。对标「接入即文档」，不是 Helios 对话用哪套模型。对话 Key 在 [settings.md](settings.md)。

## Happy path

1. 打开「AI Proxy」。看见接入地址、代码示例、近 7 天用量、Key 列表、可用模型。
2. 创建 Key：全文只出现一次，之后列表打码。可启用 / 禁用 / 删除。
3. 把示例里的地址和 Key 拷到自己的应用里用。

未在设置里接入自己的 DeepSeek Key 时，Helios 会确保一把给对话用的 Key。那不是这页要人管的对象；人要换对话模型，去设置。

## 不要

- 把这页做成对话模型设置
- 多厂商 Key、模型选择器
