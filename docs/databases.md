# 数据库

能看见、能连、能对实例动手的详情页。不把 Sealos 数据库控制台的八个 tab 搬进来。

列表和项目详情仍只展示 secret **引用名**。本页是例外：连接就是这页的工作。创建库、把库接到应用，走「开始」，见 [chat.md](chat.md)。暂停 / 启动 / 重启 / 删除见 [operate.md](operate.md)。

## Happy path

1. 数据库 tab 点卡片，或项目拓扑点库节点，进详情。列表上没有暂停 / 删除；动作在详情顶栏。
2. 一页滚到底，不要 tab 栏。顶栏：名字、引擎、状态、所属项目（点回项目）。
3. **问 Helios**：切到「开始」，新对话，输入框预填这段（可改、不发送），光标在末尾：

   ```
   请查看当前工作空间的数据库 {name}（引擎 {engine}，版本 {version}，状态 {phase}）。先不要改数据。我的问题是：
   ```

4. 统计条：状态、引擎 + 版本、CPU / 内存、存储、创建时间。
5. **连接（主角）**：集群内 host / port / 用户名 / 密码 / 连接串。密码和 URI 默认打码，点「显示」揭开，再点收起。每项可复制明文（即使当时是打码）。给一段 `DATABASE_URL`（或该引擎等价）示例。还没就绪：写「凭证尚未就绪」，不要假 URI。
6. **公网**：开关。关着只显示内网。打开后出现公网地址，同样打码 / 揭开 / 复制。失败钉在这页。
7. **被谁使用**：本工作空间里已经证实引用该库的应用。点应用进应用详情。一个都没有就写没有，不要猜。
8. **结构**：逻辑库；每个库下列表 / 集合名。只读。点名字不要打开编辑器、不要跑 SQL。引擎不支持：一句话说明 + 问 Helios。库未就绪：不探结构。
9. **健康**：近 1 小时 CPU / 内存 / 磁盘。磁盘要满了用横幅。Pods 和事件与应用详情同一套。

属于项目的库，删除确认要写明是项目的一部分、删库可能让应用连不上，并给「去项目」。

## 不要

- SQL 输入框、行编辑、spreadsheet
- 在 App 里嵌查询工具
- 创建库表单、改规格 / 参数
- Dump、备份恢复向导
- 数据库 tab 上的批量
