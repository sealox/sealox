# 应用

Launchpad 管理的工作负载。配置变更（镜像、副本、环境变量）走「开始」，见 [chat.md](chat.md)。删除 / 重启 / 暂停 / 启动见 [operate.md](operate.md)。

## Happy path

1. 打开「应用」。Launchpad 卡片可点，进详情。公网域名可点，系统浏览器打开。
2. 详情一页滚到底，和 Launchpad 同口径、不拆 tab：
   - 统计条：状态、副本、CPU / 内存、持久存储、创建时间
   - CPU / 内存曲线（近 1 小时）
   - 网络：端口 / 集群内 / 公网 / 自定义域名
   - Pods：行内展开；日志是尾部快照，不是实时流。崩溃前日志一并给
   - 配置：镜像、命令、环境变量（只显示引用名，不展示明文）、配置文件、磁盘
   - 事件：警告标红
3. 从项目拓扑点应用节点，栈上保留项目，也能进同一页。

## Launchpad 之外

能看列表，没有重启 / 暂停 / 启动 / 删除。不要为它们另造一套操作。

## 不要

- 镜像 / 副本 / 环境变量表单
- 把日志做成实时流
- 失败结构化诊断页（还没做，见 [index.md](index.md) 仍敞着的口）
