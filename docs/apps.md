# 应用

Launchpad 管理的工作负载。配置变更（镜像、副本、环境变量）走「开始」，见 [chat.md](chat.md)。删除 / 重启 / 暂停 / 启动见 [operate.md](operate.md)。

## Happy path

1. 打开「应用」。Launchpad 卡片可点，进详情。公网域名可点，系统浏览器打开。
2. 详情能看见：状态、副本、CPU / 内存、持久存储、近 1 小时 CPU / 内存、网络（端口 / 集群内 / 公网 / 自定义域名）、Pods、日志尾部快照（含崩溃前）、配置（镜像、命令、环境变量只显示引用名）、事件（警告标红）。不拆成控制台那种 tab。
3. 从项目拓扑点应用，也能进同一页。

## Launchpad 之外

能看列表，没有重启 / 暂停 / 启动 / 删除。不要为它们另造一套操作。

## 不要

- 镜像 / 副本 / 环境变量表单
- 把日志做成实时流
- 失败结构化诊断页（还没做，见 [index.md](index.md) 仍敞着的口）
