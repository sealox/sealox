# Helios 0.7 — update

相对 [vision](./vision.md) / [0.6](./0.6-database.md)：让已安装的 Helios 能发现新版本，点一下下载 dmg 并打开。不做静默替换。

包版本 `0.7.0`。

## 约束（已拍板，不要再改）

- 源码仓库保持私有。
- 没有 Apple Developer ID：包不签名、不公证。macOS **不能**替换正在运行的 `.app`。
- 不自建后端（vision 已排除）。
- 不把 token 打进客户端去读私有 Releases。

所以：探测地址和 dmg 都必须是**无需登录的 HTTPS**。

## 发行物放哪

公开仓库 [`norberia/helios-release`](https://github.com/norberia/helios-release)。源码不在那里。

| 文件 | 地址 |
|---|---|
| 清单 | `https://raw.githubusercontent.com/norberia/helios-release/main/latest.json` |
| 安装包 | 该仓 GitHub Release 附件 `Helios-{version}-mac-arm64.dmg` |

`latest.json`：

```json
{
  "version": "0.7.0",
  "notes": "给用户看的更新说明，中文，两三句。",
  "url": "https://github.com/norberia/helios-release/releases/download/v0.7.0/Helios-0.7.0-mac-arm64.dmg",
  "sha256": "64 位小写 hex"
}
```

`url` 必须是 `https://github.com/norberia/helios-release/releases/download/` 前缀。缺字段、版本不比当前新、或 url/sha256 不合格：当作没有更新。

0.7 是第一版会探测更新的 Helios。已经装了 0.6 的人看不到绿点，需要手动装一次 0.7。从 0.7 起才靠这条链路。

## 用户看见的流程

侧栏 logo 旁边。点 logo 仍回「开始」。

1. 启动时查一次，之后每 30 分钟。失败当没发生，不弹窗、不挡使用。
2. 有新版本：logo 右上角一个小绿点（`--running`）。
3. 鼠标放到绿点上：浮层显示版本号 + `notes`。
4. 点绿点（或点浮层）：主进程把 dmg 下到 `~/Downloads`，校验 sha256，用系统打开。用户把 Helios 拖进「应用程序」，自己退出再打开。Helios **不退出、不替换自己**。
5. 下载中浮层显示进度；打开后提示去拖；校验失败提示重试。进行中再点无效。

侧栏收起时绿点不出现（logo 本来就看不见）。登录页不做。

## 工程落点

做事在 Electron **主进程**，渲染进程不碰清单 URL、不下载。

- 新文件 `apps/electron/src/main/update.ts`：拉清单、比版本、下载、校验、`shell.openPath`。IPC 推送状态（与 chat event 同一套路）。
- 版本比较只认 `x.y.z`，不引入 semver 库。
- IPC / preload / `HeliosApi`：`getUpdateStatus`、`downloadUpdate`、`onUpdateEvent`。渲染进程只拿 `available` / 版本 / notes / 阶段 / 进度 / 错误。
- 渲染：`ResourcesScreen` 侧栏 logo 旁绿点 + CSS 悬停浮层。不要新页、不要 modal。
- 发布：`apps/electron/scripts/publish-mac.mjs`。假定本机已经 `npm run build:mac`。脚本算 sha256、在公开仓建 Release、更新 `latest.json`。根脚本 `publish:mac`。
- 根和 `@helios/electron`（以及 eve，与现有包版本对齐）的 `package.json` version 改为 `0.7.0`。`versions/vision.md` 版本记录补上 0.7。
- 不用 `electron-updater`。`electron-builder.yml` 里那段 `publish.generic` 是脚手架残留，打包继续 `--publish never`。

## 本版明确不做

- 签名、公证、静默替换、`quitAndInstall`
- Windows / Linux / Intel Mac
- 强制更新、启动拦截、角标数字
- 公开源码仓、自建后端、把 GitHub token 打进 App
- 改 0.2 对话、0.3 模板、0.4 操作、0.5 拓扑、0.6 数据库

## 验收

- 把公开仓 `latest.json` 的 `version` 调到比本机高、填好 url 和 sha256：启动后 logo 旁出现绿点；悬停能读到 notes。
- 点绿点：`~/Downloads` 出现对应 dmg，校验通过后自动打开。点 logo 仍回「开始」。
- `latest.json` 版本相同或更低、url 为空、或断网：没有绿点，也没有错误条。
- 下载到一半再点，不会开第二个下载。
- `npm run typecheck -w @helios/electron` 通过。
