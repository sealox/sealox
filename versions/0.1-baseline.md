# Helios 0.1 — baseline

相对 [vision](./vision.md)：把 use-sealos 链路做成桌面 MVP 的第一版功能——能登录、能看见资源、对话能部署。

## 登录

- 首次启动：OAuth2 device flow，或粘贴 kubeconfig。凭证落盘与 skill 互认，见 vision。
- 登录后默认进私人工作空间；侧边栏工作空间胶囊可切换同账号下任意工作空间（desktop 同款：`namespace/switch` 换发 token 再取新 kubeconfig，落盘 `~/.sealos/`）。

## 部署（唯一动作）

agent 按 use-sealos 决策树自动分类：

1. 模板店有现成模板 → Template API 一键部署；
2. 有官方 Docker 镜像 → 生成模板部署；
3. 用户自己的源码 → Dockerfile → linux/amd64 构建 → 推镜像 → 部署。

配套资源（数据库、对象存储、公网域名）由 agent 按项目需要自动创建。全程实时进度流：当前动作、关键决策、报错与自救。成功标准与 skill 一致：workload ready 且公网 URL 返回真实页面，否则如实报告失败原因。

入口原定拖入本地文件夹或粘贴 git 地址——**本版未做**；对话里走三条路径已经可用。

## 主界面

布局：左侧 256px 侧边栏 + 右侧内容区，视觉与结构对齐 Lovable 桌面版首页（lovable.dev/dashboard 实测 DOM/样式复刻）。配色见 vision。

### 侧边栏

工作空间胶囊点开是 Lovable 式面板：当前空间信息（私人/团队、角色、成员数）、成员列表（头像+角色）、邀请成员（生成管理员/开发者邀请链接并复制，落地页 `/WorkspaceInvite/?code=` 与 desktop 一致）、重命名（仅拥有者）、切换/新建工作空间、底部 Upgrade 栏（跳 region 费用中心）。权限门控与 desktop 相同（邀请需拥有者/管理员）。

主导航按点击频率分两组：高频 **开始、模板、项目**；资源 **应用、数据库、存储、AI Proxy**。「最近」展示最新项目。底部工作空间配额卡（CPU/内存/存储/GPU 的 used/limit，直读 namespace `ResourceQuota`——与 costcenter usage 接口同源，随资源快照 15s 轮询）。头像进**用户信息**；右下角全局刷新。

### 开始

白底＋logo 淡金日光背景 + 居中输入框（标题「今天想开发点什么？」）接到本地 eve。发送后流式显示模型回复，并展示工具活动（`load_skill` / `bash` / 读文件等）和模型若提供的 reasoning。能力范围与 use-sealos 一致：对话即可部署、排障、管数据库/存储。模板建议 chips 只填输入框。右下角常驻 "Hi · Follow me on X" 胶囊（点击外部浏览器打开 x.com/norberia_cz）。

### 项目

项目 = 模板实例（namespace 里的 `instances.app.sealos.io` CR，与 Template 前端同源直读，不再依赖 `template.{region}` 服务），由应用 / 数据库 / 存储桶构成，归属 `cloud.sealos.io/deploy-on-sealos` 标签。一张卡片：

- 状态由名下应用与数据库聚合，优先级：异常 > 启动中 > 运行中 > 已暂停；
- 模板图标与备注名（`displayName` 注解）、模板名、应用/数据库/存储桶数量、创建时间；
- 公网域名（外部浏览器打开）；
- 故障 pod 的原因与重启次数（标红）。

### 应用

与 App Launchpad 同一口径：带 `cloud.sealos.io/app-deploy-manager` 标签的 Deployment/StatefulSet。逐个展示状态、副本、镜像、公网域名与所属项目 chip。不带该标签的工作负载在「Launchpad 之外的工作负载」小节单独展示。

### 详情页

卡片点击进入；面包屑导航栈支持项目 ↔ 应用互跳；侧边栏「最近」直达项目详情。数据按需拉取（`sealos:app-detail` / `sealos:project-detail` IPC），15s 轮询；切工作空间/切 tab 时导航栈清空。

**项目详情**：图标+备注名+模板 chip+聚合状态、GitHub/官网外链、统计条（应用/数据库/存储桶/定时任务数、创建时间）、异常 Pod 聚焦横幅（点击跳对应应用）、公网入口列表。组件分区：应用（进应用详情）、数据库（引擎/版本/规格/连接凭证 secret 名）、对象存储（策略/实际桶名）、定时任务（schedule/暂停态/上次运行）、配套资源（Secret/ConfigMap/Service/Job/PVC/SA/Role/Issuer/Certificate/App CR 按 kind 分组，排除数据库内部资源 `sealos-db-provider-cr`）。

**应用详情**：与 App Launchpad 详情同口径、单页分区——统计条（状态/副本+HPA 范围/CPU/内存限额/持久存储/创建时间）；CPU/内存监控曲线（`applaunchpad.{region}/api/monitor/getMonitorData`，kubeconfig 鉴权，近 1 小时、60s 轮询，序列过滤到当前存活 pod）；网络表（端口/集群内地址/公网地址/自定义域名标记，service 按 label、同名或 selector 匹配）；Pods 表（行内展开：容器状态 chips、按需拉取日志尾部 400 行、崩溃前日志、复制全部）；配置（镜像/命令/环境变量表——valueFrom 只显示引用不显示明文、ConfigMap 挂载、持久卷）；事件流（workload+RS+pod 聚合，Warning 标红）。

### 模板

sealos.io 应用商店目录（212+ 模板，官网 `/api/apps/en`，主进程 30 分钟缓存）——分类/搜索/排序/分页，卡片样式对齐官网（浅色适配）。模板名跳官网详情；「部署」按钮暂以外部浏览器打开用户 region 控制台的模板部署页（对话里走 agent 部署已经可用）。

### 数据库 / 存储

- 数据库：KubeBlocks Cluster 列表——引擎、版本、阶段、所属实例。
- 存储：ObjectStorageBucket 列表——策略（私有/公开读/公开读写）、实际桶名、创建时间。

### AI Proxy

交互对标 Vercel/Cloudflare AI Gateway 的「接入即文档」，单页四区。数据源：`aiproxy-web.{region}` 用户侧 BFF，鉴权用 desktop 应用会话 token；30s 轮询。

- **接入卡**：OpenAI 兼容端点 `https://aiproxy.{region}/v1` + curl/Python/JS 示例（自动带第一个启用的 Key 与可用模型，复制即用）。
- **用量**：近 7 天请求数/Tokens/花费/异常统计条 + 请求数/花费按天曲线（`/api/user/dashboard?type=week`）。
- **API Keys**：行内创建（创建后金色高亮一次性提示复制）、sk- 打码展示/复制全文、启用/禁用、行内二次确认删除（`/api/user/token*`）。Helios 还会确保一把名为 `helios` 的 Key 给本地 eve（见 vision）。
- **模型目录**：搜索 + 厂商过滤 chips，类型/RPM/输入输出价（原始 /1K 换算 /1M 展示）（`/api/models/enabled`）。

### 用户信息

区域、API server、命名空间、工作空间、登录时间、kubeconfig 路径；退出登录放在此页。

留给后续：日志实时流式（详情页已有按需日志快照）、失败诊断的结构化结论。工具活动时间线已在首页。以项目为单位的整体删除见 [0.4](./0.4-operate.md)。

## 未决

1. 源码构建是否要求本机 docker；没有 docker 时的降级。当前 agent 还要求本机 `python3` 和 `kubectl`，没有则部署失败。若要对「没装 CLI 的人」可用，执行层应改成 TypeScript tool（Electron 已有 k8s 客户端），skill 只留决策树。
2. 日志「实时」的实现程度：轮询还是 watch。
3. 拖入文件夹 / 粘贴 git 作为部署入口（对话部署已经能走三条路径）。
